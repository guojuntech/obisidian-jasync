# JASync 1.0.0

JASync synchronizes Obsidian notes with S3-compatible storage. Preview and select changes before syncing, resolve conflicts, and keep local recovery copies before overwrites and deletions.

This release promotes the existing 0.2.12 implementation to 1.0.0. The plugin ID remains `jasync`; synchronization behavior, settings format and recovery data are unchanged.

## Features

- Two-way, send-only and receive-only synchronization, including explicit override/revert policies.
- Selectable sync plans, content comparison, version rechecks, conditional-write capability checks and recovery backups.
- Configurable S3 endpoint, region, bucket and prefix; optional temporary credentials and path-style addressing.
- Continuous progress, cancellation, unchanged-file fast paths and opt-in automatic synchronization.
- S3 diagnostics exported to notes, with optional verbose request logging and credential redaction.
- Mobile-safe XML validation and targeted Android HEAD response-loss handling.
- JA sync icon, completion controls and disabled AI conflict-resolution header action.

## Install or update

Use BRAT with `guojuntech/obisidian-jasync`, or extract `jasync-1.0.0.zip` into your vault's `.obsidian/plugins/` directory. The resulting directory must be `.obsidian/plugins/jasync/`.

For an existing jasync installation, disable the plugin, replace only the release files, and re-enable it. Keep that device's settings, cache and recovery directory. New devices require their own configuration and sync history. Minimum Obsidian version: 1.7.2.

GitHub Release availability is separate from approval in the official Obsidian Community directory; this release does not claim directory acceptance.

## Requirements and limits

S3 synchronization requires your own storage endpoint/account and credentials; your storage provider may charge for use. Credentials are stored locally without encryption. Recovery copies remain local until manually removed.

Files are buffered in memory; the default size limit is 30 MB. Multipart upload, resumable transfers and historical-version browsing are not implemented. Android/iOS end-to-end acceptance remains outstanding; simulated mobile failures and desktop tests do not replace device testing.

See [README](https://github.com/guojuntech/obisidian-jasync/blob/1.0.0/README.md), [implementation notes](https://github.com/guojuntech/obisidian-jasync/blob/1.0.0/docs/IMPLEMENTATION.md), and [S3 diagnostics](https://github.com/guojuntech/obisidian-jasync/blob/1.0.0/docs/S3-DIAGNOSTICS.md).
