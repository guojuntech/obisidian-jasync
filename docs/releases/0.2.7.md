# JASync 0.2.7

JASync 是 Obsidian 的 S3 同步插件，支持同步前预览和文件选择、上传下载、冲突处理，以及覆盖和删除前的本地恢复备份。最低 Obsidian 版本为 1.7.2。

修复 Android 上启用插件时报 `Buffer is not defined`、`Failed to load` 的问题。

- 移除 S3 XML 校验新增的 Node 依赖链，复用已有解析库的浏览器校验器。
- 保留 XML 完整性、DOCTYPE 拒绝、分页与同步写删保护。
- 新增无 Node 全局对象的 S3 回归测试，以及最终生产包的独立浏览器加载检查。

从 0.2.6 更新时，先禁用 JASync，将安装 ZIP 中的文件覆盖到 `.obsidian/plugins/jasync/`，再重新启用或重启 Obsidian。保留本设备的配置、cache 和 recovery，无需重新清理安装。

本次修复已在隔离环境复现和验证；Android / iOS 完整生命周期与真实云同步仍需实机验收。

验证：834 项单元测试、17 项 Obsidian 集成检查及 ESLint、TypeScript、生产构建通过。ZIP 五个文件与 dist 产物逐字节一致。

## BRAT 安装

在 Obsidian 中安装并启用 BRAT，添加仓库 `guojuntech/obisidian-jasync`，选择 `0.2.7` 并启用 **JASync**。随后填写 S3 配置，检查连接并审核首次同步计划。自动同步默认关闭。

Release 中的 `main.js`、`manifest.json` 和 `styles.css` 是 BRAT 使用的独立附件。手动安装可将 `jasync-0.2.7.zip` 解压到笔记库的 `.obsidian/plugins/`，得到 `.obsidian/plugins/jasync/`。

新设备独立配置，不复制其他设备的 `data.local.json`、缓存或恢复目录。从旧插件 ID 切换时采用全新安装，不迁移配置、缓存和同步记录。

附件包含安装 ZIP、独立插件文件、许可说明与 `SHA256SUMS`，不包含本机配置、密钥、同步记录或恢复副本。默认跳过大于 30 MB 的文件，暂不支持分片上传、断点续传或历史版本浏览。S3 服务未验证支持条件写删时，手动同步需要额外确认兼容模式。
