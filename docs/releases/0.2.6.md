# JASync 0.2.6

JASync 是 Obsidian 的 S3 同步插件，支持同步前预览和文件选择、上传下载、冲突处理，以及覆盖和删除前的本地恢复备份。

## 本版内容

- 插件 ID、安装目录、协议、样式和内部命名统一为 `jasync`，显示名称为 **JASync**。
- S3 Prefix 作为唯一远端根目录；Path Style 默认关闭。
- 同步准备、比对、复核和执行过程提供持续进度反馈。
- 已有共同基准且内容、版本未变的文件跳过重复复核；实际写删保留版本检查、确认和恢复备份。
- 不提供旧版配置、缓存或同步记录迁移；新安装生成独立设备身份。

## 使用 BRAT 安装

在 Obsidian 中安装并启用 BRAT，添加仓库 `guojuntech/obisidian-jasync`，选择 `0.2.6` 并启用 **JASync**。随后填写 S3 配置，检查连接并审核首次同步计划。

Release 中的 `main.js`、`manifest.json` 和 `styles.css` 是 BRAT 使用的独立附件。手动安装可将 `jasync-0.2.6.zip` 解压到笔记库的 `.obsidian/plugins/`，得到 `.obsidian/plugins/jasync/`。

从旧插件 ID 切换时采用全新安装，重新填写 S3 配置并建立同步基准。其他设备不要复制当前设备的凭据、cache 或 recovery。自动同步默认关闭。

## 验证与已知边界

- 829 项单元测试、16 项隔离的 macOS / Obsidian 1.13.7 原生集成检查通过；发布流水线再次运行单元测试、ESLint、TypeScript 和生产构建。
- 最低 Obsidian 版本为 **1.7.2**。Android / iOS 尚未完成实机验证，BRAT 安装成功不代表移动端同步已通过验收。
- 默认跳过大于 30 MB 的文件，暂不支持分片上传、断点续传或历史版本浏览。
- S3 服务未验证支持条件写删时，手动同步需要额外确认兼容模式；该模式无法消除多端同时修改造成的竞争。

附件包含安装 ZIP、独立插件文件、许可说明与 `SHA256SUMS`。安装包不包含本机配置、密钥、同步记录或恢复副本。
