# JASync 0.2.12

停用笔记顶部的 AI 冲突处理按钮，并调整同步完成界面的按钮状态。

- 不再注册 AI 冲突检测服务，也不会因设置刷新重新显示该按钮。
- 同步结束后，**Stop sync** 保持可见，变为灰色且不可点击。
- 同步成功完成时，**Close** 显示为绿色背景、白色文字；再次同步时恢复正常的 Stop sync 和 Hide 状态。

通过 BRAT 更新 `guojuntech/obisidian-jasync` 到 **0.2.12**，或使用 `jasync-0.2.12.zip` 手动更新，保留原有配置、cache 和 recovery。更新后重新加载插件即可生效。

验证：71 个单元测试文件 / 903 项测试、19 项原生桌面 Obsidian 检查、ESLint、TypeScript、生产构建和 ZIP 五文件内容校验通过。界面检查包含实际按钮颜色、禁用状态及再次同步时的状态恢复。
