# JASync 1.0.1

修复同步进度窗口在文件切换和同步结束时抖动的问题。

- 当前文件名区域保留一行高度；文件同步结束时清空文字，下一项开始时显示新的文件名。
- 长文件名继续在单行内省略显示；预备阶段没有状态详情时仍保持紧凑布局。

通过 BRAT 更新 `guojuntech/obisidian-jasync` 到 **1.0.1**，或将 `jasync-1.0.1.zip` 解压到笔记库的 `.obsidian/plugins/` 目录，重新加载 JASync。最低 Obsidian 版本为 **1.7.2**。

原生桌面 Obsidian 布局实测覆盖普通文件名、长文件名、文件间空档、最后一个文件结束及同步完成、警告和错误状态。在 560px / 13px 字号及 360px / 18px 字号两组布局中，文件名行高度保持稳定，进度卡片和窗口的垂直位移均为 0。

验证：71 个单元测试文件 / 903 项测试、19 项原生桌面 Obsidian 检查、ESLint、TypeScript、生产构建和 ZIP 五文件内容校验通过。
